## Evidence and Uncertainties

- **Strongest evidence:**
  - Read the Docs hosting is confirmed both by infrastructure headers (`x-rtd-*`) and a direct on-page credit in the footer — rare case of two independent confirmations agreeing exactly.
  - Sphinx + Alabaster theme is confirmed by exact, unmistakable default asset filenames that Sphinx generates automatically and are not typically renamed.
  - Simple Analytics is named directly in an HTML comment and its script URL, leaving no ambiguity.
- **Direct observations vs deductions:**
  - Direct: all `x-rtd-*`, `x-amz-*`, and `CF-*` headers; Sphinx/Alabaster/Pygments asset filenames; Font Awesome version string in its own URL; Simple Analytics script tag and comment.
  - Deductions: Python as the underlying language is inferred from Sphinx being a Python tool, not observed directly on the site. The `ablog` blog extension is inferred only from the presence of an Atom feed at a path ablog commonly uses — this is a single weak signal and could instead be a hand-rolled or differently-named Sphinx extension.
- **Unresolved questions:**
  - Exact Sphinx, Alabaster, and Python versions — would require access to the site's build configuration or repository (this appears to be an open-source project per the GitHub link, so `conf.py`/`requirements.txt` may be publicly discoverable outside this HTTP-only pass).
  - Whether the blog is built with `ablog` specifically or a custom Sphinx extension — would require inspecting the site's source repository.
  - Full list of any Sphinx extensions in use beyond what's inferable from output (e.g. sitemap generation, search backend) — Read the Docs' own addons (`readthedocs-addons.js`) also contribute some features (e.g. search, version switching) that could be mistaken for site-authored functionality.

## Recreation Guidance

- **Recommended minimal dependency set (recommendation, not confirmed fact):** Sphinx with the Alabaster theme, Pygments (bundled with Sphinx) for code highlighting, optionally `ablog` if blog/news functionality is wanted, hosted on Read the Docs (free for open-source docs) or any static host capable of serving Sphinx's HTML output, Cloudflare (or any CDN) in front, Font Awesome 4.x for icons, and Simple Analytics (or any privacy-focused analytics alternative such as Plausible) for traffic stats.
- **Version constraints:** None verified from public evidence; Font Awesome is confirmed at exactly 4.0.3 since it's in the CDN URL. Use current stable Sphinx/Alabaster unless a build manifest becomes available.
- **Unknowns to investigate before implementation:** Confirm exact Sphinx/Python versions and full extension list via the project's public GitHub repository (linked in the footer) rather than further HTTP probing.
