## Evidence and Uncertainties

- **Strongest evidence:** The `<meta name="generator">` tag giving an exact MediaWiki version is the single strongest, most direct piece of evidence in this entire project so far — no inference needed. The `RLCONF`/`RLSTATE` JS objects are MediaWiki/ResourceLoader's own internal config dump embedded in every page, confirming a long list of installed extensions (VisualEditor, FlaggedRevs, ConfirmEdit, MultimediaViewer, ULS) directly rather than by guesswork.
- **Direct observations vs deductions:** Nearly everything in this report is a direct observation — MediaWiki pages expose an unusually large amount of their own configuration in plain JS objects, which is atypical compared to most commercial sites. The one deduction is treating the huge CSP allow-list as evidence of an ecosystem of *optional* gadgets/tools rather than core dependencies — that list is far too broad to represent the Main Page's own direct stack, and is flagged as Low confidence for that reason.
- **Unresolved questions:**
  - Exact Vector skin version/build and MediaWiki extension versions (only the core MediaWiki version is stated; individual extension versions are not exposed on this page).
  - Full backend architecture (database engine, search backend, job queue) — Wikimedia publishes some of this information on separate engineering/wiki pages, but none of it is visible from this HTTP request.
  - Which of the many CSP-allow-listed third-party domains are actually used by the rendered Main Page versus only available for optional user scripts/gadgets elsewhere on the site.

## Recreation Guidance

- **Recommended minimal dependency set (recommendation, not a claim about Wikimedia's full production stack):** MediaWiki core (matching or close to 1.47.x), the Vector 2022 skin, and the extensions confirmed above (VisualEditor, FlaggedRevs, ConfirmEdit, MultimediaViewer, Universal Language Selector) if that functionality is wanted. MediaWiki is self-hosted PHP software with its own database (MySQL/MariaDB by convention, not confirmed here) — this is a known property of the platform, not something observed on this specific page.
- **Version constraints:** MediaWiki version is verified directly (`1.47.0-wmf.21`, a Wikimedia-specific deployment branch — the public MediaWiki release equivalent would be a recent 1.43+ stable). Extension versions are unverified.
- **Unknowns to investigate before implementation:** Confirm which extensions are actually required vs Wikimedia-specific customisations by checking MediaWiki's public extension documentation and Wikimedia's own architecture documentation (outside the scope of this HTTP-only pass).
