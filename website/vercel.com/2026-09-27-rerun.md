## Evidence and Uncertainties

- **Strongest evidence:**
  - `X-Powered-By: Next.js, Payload` is a direct, high-confidence server header naming both the frontend framework and CMS explicitly, re-observed unchanged today.
  - The `Vary` header listing `rsc`, `next-router-state-tree`, `next-router-prefetch`, and `next-router-segment-prefetch` is a strong, direct fingerprint unique to the Next.js App Router.
  - `Server: Vercel` plus `X-Vercel-Id`/`X-Vercel-Cache` headers directly confirm the site is hosted on Vercel's own platform.
- **Direct observations vs deductions:**
  - Direct observations: response headers (`X-Powered-By`, `Vary`, `X-Nextjs-Prerender`, `Server`), CSP allow-lists.
  - Deductions: that Turbopack is the production bundler is inferred from chunk filename strings observed in the original pass — suggestive but not certain, and not re-verified independently in this header-focused rerun; Geist as the deployed typeface is inferred from CSP font-source allow-listing and filename strings, not a rendered visual comparison.
- **Unresolved questions:**
  - Exact Next.js, React, and Payload CMS versions — would require an exposed build manifest, `package.json`, or source map, none of which were located.
  - Whether Payload CMS is used for all marketing content or only specific sections (e.g. blog/changelog) — would require probing multiple content-heavy routes.
  - Whether styling uses Tailwind CSS, CSS Modules, or a custom in-house system — hashed `.css` chunk filenames are opaque.
  - Full extent of the `agent-skills`/`ai-catalog` well-known endpoints referenced in the `Link` header — re-observed today (`/.well-known/api-catalog`, `/.well-known/ai-catalog.json`, `/.well-known/agent-skills/index.json`), purpose/consumers still unconfirmed from public evidence.

## Recreation Guidance

- **Recommended minimal dependency set (recommendation, not confirmed fact about Vercel's stack):** Next.js (App Router, latest stable) with React, Payload CMS (or any equivalent headless/self-hosted CMS) for content-managed sections, Turbopack or Webpack as the bundler, a variable web font served self-hosted (e.g. Geist, freely available from Vercel's open-source font package, or a similar substitute), Vercel Blob or any S3-compatible object storage for media assets, and an analytics/RUM tool such as Vercel Analytics or a self-hosted equivalent (e.g. Plausible, PostHog) plus Sentry for error tracking.
- **Version constraints:** None verified from public evidence; use current stable releases of Next.js/React/Payload unless a build manifest becomes available.
- **Unknowns to investigate before implementation:** Confirm exact Next.js/Payload versions via any exposed manifest; determine the styling approach (utility CSS vs CSS Modules) by inspecting rendered class names; clarify scope of Payload CMS usage across the site's routes.
