## Evidence and Uncertainties

- **Strongest evidence:**
  - `X-Powered-By: Next.js, Payload` is a direct, high-confidence server header naming both the frontend framework and CMS explicitly.
  - The `Vary` header listing `rsc`, `next-router-state-tree`, `next-router-prefetch`, and `next-router-segment-prefetch` is a strong, direct fingerprint unique to the Next.js App Router.
  - `Server: Vercel` plus asset paths prefixed `/vc-ap-vercel-marketing/` directly confirm the site is hosted on Vercel's own platform (unsurprising, but verified rather than assumed).
- **Direct observations vs deductions:**
  - Direct observations: response headers (`X-Powered-By`, `Vary`, `X-Nextjs-Prerender`, `Server`), CSP allow-lists, font/script filenames.
  - Deductions: that Turbopack is the production bundler is inferred from a single chunk filename containing "turbopack" — this is suggestive but not certain since Next.js may retain such naming across build-tool changes or the string could reflect a specific chunk-splitting strategy rather than the whole build; Geist as the deployed typeface is inferred from filename strings, not a rendered visual comparison.
- **Unresolved questions:**
  - Exact Next.js, React, and Payload CMS versions — would require an exposed build manifest, `package.json`, or source map, none of which were located in this pass.
  - Whether Payload CMS is used for all marketing content or only specific sections (e.g. blog/changelog) — would require probing multiple content-heavy routes for consistent CMS-related headers or exposed API routes (e.g. `/api/*`, though `robots.txt` disallows crawling `/api/`, suggesting an API surface exists but its shape is not publicly documented).
  - Whether styling uses Tailwind CSS, CSS Modules, or a custom-in-house system — the `.css` chunk filenames are hashed and opaque; would require inspecting compiled class names in rendered DOM.
  - Full extent of the `agent-skills`/`ai-catalog` well-known endpoints referenced in the `Link` header — these appear to be new/non-standard machine-discovery routes; their purpose and consumers are not confirmed from public evidence alone.

## Recreation Guidance

- **Recommended minimal dependency set (recommendation, not confirmed fact about Vercel's stack):** Next.js (App Router, latest stable) with React, Payload CMS (or any equivalent headless/self-hosted CMS) for content-managed sections, Turbopack or Webpack as the bundler, a variable web font served self-hosted (e.g. Geist, freely available from Vercel's open-source font package, or a similar substitute), Vercel Blob or any S3-compatible object storage for media assets, and an analytics/RUM tool such as Vercel Analytics or a self-hosted equivalent (e.g. Plausible, PostHog) plus Sentry for error tracking.
