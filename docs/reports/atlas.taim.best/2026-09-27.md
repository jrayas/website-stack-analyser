## Evidence and Uncertainties

- **Strongest evidence:** The Tailwind CSS version is stated explicitly and unambiguously in the CSS file's own license comment — a rare case of an exact, directly-verified version number. React is confirmed with very high confidence because the scheduler package's internal function/variable names are extremely distinctive and not something another framework would replicate. The SPA architecture is confirmed structurally: an essentially empty HTML shell plus a single hashed JS bundle is a textbook Vite+React SPA build output.
- **Direct observations vs deductions:** Direct: Tailwind version string, React scheduler source, `THREE.*` class names, Vite-pattern asset filenames, Cloudflare headers. Deductions: that `OrbitControls` and the overall 3D setup are used via the raw Three.js API rather than through a React wrapper library like `@react-three/fiber` — no `useFrame`, `useThree`, or `@react-three/fiber`-specific strings were found in the bundle, which is itself evidence of absence (weakens the case for r3f) but isn't conclusive proof it's absent, since minification could obscure such strings.
- **Unresolved questions:**
  - Exact React, Three.js, and Vite versions — none are stated directly; would require an exposed `package.json`, lockfile, or source map, none of which were found in this pass.
  - Whether a React-Three.js integration layer (e.g. `@react-three/fiber`) is used, or whether Three.js is driven directly via refs/imperative code — bundle text search found no r3f-specific hook names, but this is not conclusive given minification.
  - Where the anatomical 3D model data itself is hosted/loaded from (e.g. a CDN-hosted GLTF/GLB file) — not identified in this pass since only the JS/CSS bundle text was searched, not runtime network requests.
  - The actual hosting provider behind Cloudflare (Cloudflare is a CDN/proxy in front of the origin, not necessarily the origin host itself) — origin server identity is masked by Cloudflare's proxying.

## Recreation Guidance

- **Recommended minimal dependency set (recommendation, not a confirmed fact about the original site's exact package list):** React + ReactDOM, Three.js for 3D rendering (optionally with `@react-three/fiber` and `@react-three/drei` if a React-idiomatic 3D workflow is preferred over raw Three.js), Tailwind CSS v4.x for styling, Vite as the build tool, and Lucide for icons.
- **Version constraints:** Tailwind CSS is confirmed at exactly `4.2.1` — recreate with that exact version for closest fidelity. All other versions are unverified; use current stable releases.
- **Unknowns to investigate before implementation:** Confirm whether Three.js is used directly or via a React wrapper (affects component architecture significantly), and locate the source/format of the 3D anatomical model assets (likely GLTF/GLB, common for web-based 3D) by inspecting actual network requests in a browser — this pass only searched static bundle text, not runtime behaviour.
