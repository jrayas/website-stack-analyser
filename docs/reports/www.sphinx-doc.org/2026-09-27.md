## Evidence and Uncertainties

- **Strongest evidence:** Same strength of evidence pattern as the `writethedocs.org` report — Read the Docs hosting is confirmed via both `x-rtd-*` headers and the robots.txt notice. The `sphinx13.css` filename is a distinctive signal specific to this exact project (Sphinx's own docs use their own theme, not the more common Alabaster default), and a direct GitHub source link removes any doubt about the project identity.
- **Direct observations vs deductions:** Nearly everything here is directly observed from standard Sphinx-generated filenames and Read the Docs infrastructure headers — very little inference was required, since documentation sites tend to expose their generator's fingerprints unusually clearly compared to commercial sites.
- **Unresolved questions:**
  - The exact Sphinx version used to build this specific instance of the site is not exposed on-page (no generator meta tag was found here, unlike on some other Sphinx sites) — would require checking the public `sphinx-doc/sphinx` GitHub repository's own `docs/` build configuration.
  - Whether any additional Sphinx extensions beyond `graphviz` are active (e.g. autodoc, intersphinx) — these often don't leave a client-visible fingerprint on a documentation index page and would need repository access to confirm.

## Recreation Guidance

- **Recommended minimal dependency set (recommendation, not a confirmed fact about the exact deployed version):** Sphinx with a custom theme (or reuse the open-source `sphinx13` theme if available, since Sphinx's own docs are open source), Pygments (bundled with Sphinx) for syntax highlighting, the `sphinx.ext.graphviz` extension for diagrams, hosted on Read the Docs or any static host, with Cloudflare (or any CDN) in front.
- **Version constraints:** None verified from public evidence; recommend the current stable Sphinx release given this is the project's own documentation and likely tracks recent releases closely.
- **Unknowns to investigate before implementation:** Confirm the exact Sphinx version and extension list via the public `sphinx-doc/sphinx` GitHub repository rather than further HTTP probing — this is an open-source project, so ground truth is directly available outside this analysis's public-evidence-only scope.
